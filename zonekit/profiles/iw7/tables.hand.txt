# IW7 hand tables: the readers the transcriber leaves UNSUPPORTED, each read off the disassembly.

### f9f0900
# GfxWorld's array of pointers (0x9f0900, the loop at 0x9f0940): a non-null element allocates in
# block 7, then 0xa7ca20(4) reads a u32 count into the temp block (push 0, align 4, file_read,
# pop) and 0x9f0700(1, count) reads count 0x38-byte records, each with its reader f9f0700.
SELF|0x8
IF|u64@0x0 != 0
MARK|count_at
READ|4
SUM|count|u32|$count_at|1
ARRAY|$count|0x38|f9f0700
ENDIF

### fa19d40
# a navmesh array element (0xa19d40): the pointer at 0x60, when non-null, allocates aligned 4 and
# Load_Streams i32@0x18 bytes if u8@0x54 is set, none otherwise (0xa19e22..0xa19e65)
SELF|0x68
BYTES+|0x58|i32@0x18
BYTES+|0x60|((u8@0x54 != 0) * i32@0x18)
